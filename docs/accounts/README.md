# テーマ別アカウント 運用ガイド（9アカウント×4SNS）

OLD ORDERの専用リンク（スタッフ歩合）で売るための、ホビ垢・関係なさそう系アカウント。
毎週の投稿計画は `python -m affiliate.cli plan --start YYYY-MM-DD --week N --out docs/accounts/week_YYYY-MM-DD` で作る。

## 共通ルール（法務チェック済み）
- 中の人は「OLD ORDERスタッフ（チーム）」。架空の個人を装わない
- プロフィールに運用者を書く（下の文面にすべて入っている）
- OLD ORDERが出る投稿だけ、1行目に `【PR】OLD ORDERスタッフ運用`。TikTok・X・YouTubeは広告表示の設定もON（公開前に確認）
- OLD ORDERを出さない投稿には何も付けない（関係がないため）
- 他社の画像・ロゴは使わない。自分で撮影するか、各SNSの共有・引用機能を使う。他社を下げない
- 他社の発売日・価格・イベントは公式発表で確認してから出す（下書きでは【要確認】）
- 体験していない体験談・根拠のない最上級・他店比較・効果の断定（細見え・疲れにくい等）は書かない
- AI背景はコラージュ・グラフィック調（ラベル不要）。リアルな背景やAI動画・AI音声はラベルON
- 同じ投稿を別のアカウントで流さない。アカウント同士でいいね・フォローし合わない

## 立ち上げチェックリスト

- [ ] 会社の確認: スタッフが他社ブランドも紹介するアカウントを複数運用してよいか、歩合の対象になるか（9アカウント×4SNS）
- [ ] 専用リンクの発行: アカウント×SNSごとに1本（36本）→ `affiliate/data/account_links.json` に入れる
- [ ] アカウント作成: SNSごとにメール・電話番号を分ける（Instagramは1端末5アカウントまで切替可）
- [ ] Instagramはプロアカウントにする（予約投稿・API連携のため）
- [ ] TikTok・YouTubeのプロフィールにリンクを置けるか確認（条件がある場合あり）
- [ ] プロフィール文を設定（上の文面）
- [ ] 予約投稿ツールを決める（4SNS対応のもの）
- [ ] 毎週: 計画を生成 → 【要確認】の下書きを埋める → 画像・動画を作る → 公開前チェック → 予約

## 毎週の流れ

1. 月曜: 計画を生成（9アカウント×7日×4SNS＝252件。うちOLD ORDER回は各アカウント週5回）
2. 月〜火: 【要確認】の下書きを、公式発表を見ながら埋める（Claudeに調べさせる）
3. 火〜水: 画像・動画を作る（図解カードは自動、撮影が要るものはスタッフ）
4. 水: 公開前チェック（広告表示・禁止表現・在庫）→ 予約
5. 日: 専用リンクの件数を見て、伸びた型を翌週に増やす
