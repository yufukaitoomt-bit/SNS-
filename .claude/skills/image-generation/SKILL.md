## 1. モデル設定

higgsfield MCP の `generate_image` を使う。

```
model:         nano_banana_pro
aspect_ratio:  4:5   （Instagramフィード。ストーリーは 9:16）
resolution:    2k
count:         2     （同一プロンプトの振れ幅を見るため、常に2枚以上）
use_unlim:     false
```

- **コスト**: 2クレジット/枚。`get_cost: true` で事前確認できる
- **参照画像**: `medias: [{role: "image_references", value: "<media_id>"}]`。
  `media_upload` → curl PUT → `media_confirm` の順。ローカルに読めるファイルがあるなら
  `media_upload_widget` ではなく自分でアップロードする
- **待ち方**: `jobs_wait`（最大15秒）を `all_terminal: true` になるまで繰り返し、
  最後に `show_generation_by_ids` で1回だけ表示する

### ネットワーク制限に注意

環境によっては以下が遮断され、**参照画像を渡せず、生成物を検品できない**。

- `upload.higgsfield.ai` — 参照画像のアップロード先
- `d8j0ntlcm91z4.cloudfront.net` — 生成物の配信元

遮断されている場合は、**結果を自分で見られていないことを必ずユーザーに伝える**。
見ていないものを「できました」と報告しない。

## 2. プロンプト規則

**最重要**: AIに「リアルに」と言うと、AIは作り込む。作り込みは実写から遠ざかる。
**完成度を下げる指示の方が、実写に寄る。**

### 避ける語

画質を上げる言葉ほどAI感が出る。以下は使わない。

```
美しい / beautiful        高品質 / high quality / high-end
4K / 8K / ultra HD        シネマティック / cinematic
flawless / perfect        crisp / glossy / polished
commercial finish         professional photography
masterpiece               highly detailed
```

### 効く語

劣化・制約・具体的な破綻を書く。

```
f/1.8                     手ブレ / slight motion blur
高ISO / high ISO          前ピン / focus landing slightly in front
色あせた / washed out     アンダー / underexposed
2m先は読めない            顔の右半分は黒に落ちている
緑に寄った色              誰もカメラを見ていない
```

### 書き方

- **英語で書く。** 写真用語の作例が英語に偏っているため、英語の方が効く
- **雰囲気語は訳さない。見た目に分解する。**
  「地雷系」→ ❌ `jirai-kei style` / ⭕ 具体的な髪・服・表情・姿勢の描写に展開する
- **光は場所を指定する。** 「暗い店内」ではなく
  「左の画面だけが光源。顔の右半分は黒に落ちて何もない」と書く
- **プリントの文字は指定しない。**（→ 5章）生成で必ず別物になるので
  `A printed graphic sits on the chest` 程度にとどめ、文字を書かせない。
  指定すると潰れた文字が生成され、貼り替え作業が増えるだけ

## 3. プロンプト雛形

構成は固定。**撮影条件を最後に置く**と、被写体の描写が条件に引きずられにくい。

```
A snapshot taken [場所] at [時間帯]. [人数].

[被写体A]: [髪・表情・姿勢・手の位置]。[この人物に当たっている光と、落ちている影]。

[被写体B]: [同上]。[AとBの関係・距離]。

Both wear [服の状態 — 新品ではなく、どう褪せ・伸び・汚れているか]。

[環境 — 具体物を3〜5個。遠景は「読めない」と書く]。

Shot handheld on a small sensor camera, f/1.8, high ISO, a little motion blur
because the shutter was too slow, focus landing slightly in front so [手前の物]
is sharper than the face. The colours are washed out and lean green.
Underexposed. Nothing is retouched, nothing is posed, nobody is looking at the camera.
```

## 4. 仕上げ（ザラつき処理）— ❌ 未入手

**原典**: `~/画像生成/仕上げ/つかいかた.md`

分かっている要点のみ記す。**これだけで実装しないこと。**

- **「ザラザラ」には2種類ある。** 写真由来のノイズは**残す**。AI特有の網目だけ消す
- **量を減らすのではなく、性質を入れ替える。** 実測で 0.0104 → 0.0102 と、総量はほぼ変わらない
- **明るさは一様に上げない。** 光源の側から、顔ほど強く

原典が手に入るまで、この章の処理は**実行しない**。
ユーザーに原典を要求し、入手できるまでは生成までで止める。

```
共有ドライブ/11. マニアジャパン/中国/
```

49モデル・約250色・画像9,043枚。1色につき15〜20枚で、

## 6. 既知の失敗

同じことを繰り返さないための記録。

### 失敗1: プロンプトで画質を上げようとした

ザラつきを消そうとして `high-end` `flawless` `crisp` `perfectly smooth`
`glossy high resolution commercial finish` を並べた。
**結果、AI感が増した。** 2章の「避ける語」はこの失敗から来ている。

### 失敗2: ノイズを減らす方向で後処理した

中央値フィルタ＋ガウシアンでノイズ**量**を削った。
**4章が「2回失敗した」と名指ししている方向そのもの。**
写真らしいノイズまで消えて、のっぺりしたAI画像になる。

### 失敗3: 結果を見ずに報告した

ネットワーク制限で生成物をダウンロードできない環境で、
生成が成功したことをもって「できました」と報告しかけた。
**見ていないものは「見ていない」と言う。**
