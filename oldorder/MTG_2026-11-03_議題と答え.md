# 議題1の答え｜11/4入荷・11/7再販

## 段取り

```
11/4(水)  荷物到着
          東京：店舗スタッフ3人で入荷作業 → 開店前 or 閉店後
          大名：倉庫で検品開始（髙橋さん）
11/5(木)  検品
11/6(金)  検品完了・値付け・陳列準備
11/7(土)  ★再販開始
            再入荷 30型 1,312足 ＝ 全部
            新作 第1弾 約900足（41-43が揃う14型を中心に）
11/20(金) 新作 第2弾 約404足（三連休 11/21〜23 の直前）
```

## 作業量は問題ない

| 行き先 | 足数 | 体制 | 所要 |
|---|---|---|---|
| 東京（原宿・裏原） | 704足 | 店舗スタッフ3人 | **1人1日78足**（3日で） |
| 大阪・名古屋 | 1,912足 | 倉庫・髙橋さん1人 | **1.9日**（キャパ2.5日） |

商品登録は済んでいるので、**業務委託・タイミーの手配は不要**。

## ★東京は営業中に3人同時に入らないこと

11/4〜6は水木金で営業日。原宿は平日でも26〜35人来る。

| 曜 | 原宿の日商 |
|---|---|
| 水 | ¥242,464 |
| 木 | ¥222,738 |
| 金 | ¥211,487 |
| **3日計** | **¥676,689** |

**3人が売り場を空けて決定率が10%落ちると ¥67,669 の機会損失。**
1人1日78足なら**開店前1時間で終わる量**なので、営業中にやる必要がない。

```
開店前（1時間）か閉店後にやる
または1人ずつ交代で、常に2人は売り場に残す
```

## 再入荷は分けない

**分けると販売機会が27%減る**（1,312足を半分ずらすと31,488→22,960足日）。しかも分ける理由が1つもない。

| | |
|---|---|
| 目的がサイズの穴を埋めること | 遅らせると目的そのものを失う |
| 既存の棚に足すだけ | 新作と違い売り場を作る必要がない。分けても手間が減らない |
| 話題性が新作より弱い | 「Turbo GTが再入荷」は訴求が弱い |
| **ルール3が回らない** | 裏原はペア表が2型しか作れない。再入荷で初めて成立する |
| 入荷連絡が出せない | 「11/7に入荷します」と言った型が出てないと連絡できない |

## 新作は3回ではなく2回（10/27案から変更）

「足日」＝在庫×売り場に出ている日数で比べる。

| | 足日 | 一気との差 |
|---|---|---|
| 11/7に全部 | 31,296 | — |
| **2回（11/7・11/20）** | 26,044 | **−17%** |
| 3回（11/7・11/20・11/26） | 19,776 | **−37%** |

```
11/7  投入 → 11月中 24日売れる
11/20 投入 → 11月中 11日
11/26 投入 → 11月中  5日  ← これでは11月の数字にならない
```

**新作は立ち上がりに時間がかかる**（90日÷30日比で新作は1.0〜1.6＝まだ伸び途中）。
5日しか売れない型は11月の予算に貢献せず、12月に回るだけ。

一方で分けて得られるのは、投入日の来客増。4店の金曜70.8人が+20%で+14.2人、決定率34.1%・客単価¥23,031なら**+約11万円/回**。
**第3弾（11/26）は得るもの（約11万）より失うもの（360足が11月に売れない）が大きい。**

**ブラックフライデー（11/27）は新作ではなく、11/7・11/20で反応が分かった型を厚く出す＋アーカイブセールで戦う。**

# 議題3の答え｜ハロウィンの結果

## 4店すべて来客が減った

|---|---|---|---|---|---|

| 名古屋 | 16人 | 30.2人 | **−47%** | ¥39,980 | **−65%** |
| 大阪 | 18人 | 30.0人 | **−40%** | ¥167,466 | **−39%** |

## セール明けの谷ではない

会員セールは10/29に終わったので「明けの谷」を疑ったが、**10/30(金)は2店が上がっている。**

| 店 | 10/30(金) vs 金曜平均 | 10/31(土) vs 土曜平均 |
|---|---|---|
| 原宿 | **+26%** | −19% |
| 裏原 | **+11%** | −27% |
| 名古屋 | −5% | −47% |
| 大阪 | −24% | −40% |

**前日が持ちこたえて翌日だけ4店同時に落ちたなら、原因は10/31固有のもの。**
つまり**ハロウィン当日の効果**。人が仮装イベントに流れて買い物をしない。

## 試作としての結論

**「ハロウィン当日に小売の集客企画をやるのは逆効果」。**
来年は10/31ではなく、**その前の週末（10/24-25あたり）に寄せる。**

原宿だけ来客−19%でも売上+2%（客単価が上がった）。少ない客で売れた点は評価できる。

## ただし売上では測れない

**この企画の目的は売上ではなくLINE会員とフォロワーの獲得だった。**
**売上では失敗でも、会員獲得では成功している可能性がある。**

**回収する数字**
```
大阪  くじ参加数 / 1等・2等の消化 / 新規フォロワー（店舗・styling）/ 新規会員登録数
東京・名古屋  LINE新規登録数 / お菓子の配布数
全店  来店数（確定済み）
```

**11/7(土) に再確認すること**
```
フォロワー・LINE会員が残っているか（1週間後の残存率）
残存80%以上 → 他店に展開
50%未満     → フォロー・登録条件の企画自体を見直す
```

# 議題5の答え｜3つのルールの初動

11/1開始で、11/3は3日目。**早すぎる確認ではない。定着は初週で決まる。**

10/06で指示した立ち位置が10/19に守られていなかった実例があるので、**最初に確認するのが大事。**

## 今週の武器

**11/7(土)に再入荷が入るので、「11/7に入荷します」と日付で言える。**

```
×「サイズ無いですね」
○「11/7に入荷します。入ったらご連絡しますね」＋連絡先
```

**日付が言えるのは今週だけの強み。** 入荷連絡票をもらった人に11/7の再販開始を連絡すれば、そのまま来店理由になる。

## 確認すること

```
□ 試着ログが書かれているか（枚数を見る。書かれていないなら理由を聞く）
□ ルール1「他店を見る」で取り寄せ・入荷連絡が出ているか
□ ルール2「レジでもう1つ」の景品が置かれているか
□ ルール3「試着は2足から」のペア表が使われているか
□ 各店の担当者が機能しているか
```

**「できていない」を責めない。** できていない理由（忙しい／紙がない／言い方が分からない）を集めて、11/7の再販までに直す。

# 議題6の答え｜遅刻欠勤スレッド

**結論：分けるかどうかの前に「記録がどこにあるか」が先。**

```
チャットは連絡手段であって記録ではない
10/20の宿題に「給与計算を正確に行うため日々の勤怠管理を確実に実施」がある
→ 記録が別にあるなら、スレッドを分けても全体把握は失われない

連絡 → 店舗ごとに分ける（見落とし防止・店長の責任が明確）
記録 → システムかシートに集約（統括・人事がいつでも見れる）
```

**落とし穴**：記録がないまま分けると、店長が握り込める構造ができる。
10/06で髙橋さんが龍太さんについて「よう休む」「信用できん」と発言、10/20で枡田さんが復職可否を診断書で確認する宿題を持っている。**慢性欠勤は動いている案件なので、このタイミングで見えなくするのは危ない。**

**あわせて周知すること**：「気まずさで休みを抑制する」設計は降ろす。体調不良で出てくるほうが接客の質も落ちるし他に移る。

**数字が未集計なら、この議題は次回に回す。** 印象論でやると結論が出ない。
