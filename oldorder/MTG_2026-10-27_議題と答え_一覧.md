## 議題3の答え｜反省 → 11月の対策

| 反省 | 11月の対策 |
|---|---|
| **クロージングが4店全部落ちた** | **ルール1「他店を見る」**でサイズ欠けを潰す ＋ **試着ログ**で落ちた原因を実測する（今は記録がないので分からない） |
| 原宿：客単価が4週連続で下落 | **ルール3「試着は2足から」**で比べてもらう ＋ 高単価型を手前に出す |
| 大阪：試着は増えたがクロージングが落ちた | **ルール1。**試着まで行って買われない＝サイズ欠けの疑いが最も濃い |
| 名古屋：試着率が4週間動かなかった | **土日に人を厚くする**（来客が平日の2.1倍なのに試着率が下がる）＋ **まず履いてもらう1足を固定**（Turbo GT） |
| 裏原：試着率が4週連続で低下、来客増を取れていない | **ルール2「レジでもう1つ」**（Leg Warmers を原宿へ寄せ、Shoe Clip を出す）＋ **Turbo GT 95点の出し方**を変える |

### 全店共通の3つのルール（開始 11/1 日）

```
ルール1「他店を見る」     サイズが無いとき →「他の店にあるか見てきますね」
                         ├ あれば  「取れそうです。確認して連絡します」
                         └ なければ「入荷したら連絡しますね」＋連絡先
                         ★日付は約束しない（本国からの補充は1ヶ月）

ルール2「レジでもう1つ」  購入が決まった直後に1点出す
                         ★Leg Warmers：原宿 在庫12点で30日27点／裏原 在庫60点で15点
                           → 裏原から原宿へ寄せるのが今日いちばん確実な一手

ルール3「試着は2足から」  「比べたほうが分かりやすいので、もう1足持ってきますね」
                         ★効くかは未確認。11月に測る（足/組とクロージングに相関が出ていない）
                         ★裏原は41-43揃いが2型のみ＝ペア固定できない
```

**3つとも試着ログ1枚で測る** → 取り寄せ提案率／2足率／2足のときのクロージング差／帰られた理由／足りていない型とサイズ
**週1回こちらから数字を返す。最初の2週間は店長が1日1件だけ確認**
