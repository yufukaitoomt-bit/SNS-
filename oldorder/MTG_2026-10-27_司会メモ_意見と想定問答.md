# 議題2｜11月の3つのルール

## 自分の意見

**結論：3つとも決定事項。やるかやらないかは議論しない。**

理由を正直に言う：**この会社は口頭の指示が定着していない。** だから今回は紙と担当者を必ず決める。

| 指示 | いつ | 結果 |
|---|---|---|
| 立ち位置・通りすがりへのアイキャッチ | 10/06 全店に指示 | **10/19の原宿で棒立ち2名、通りすがりへのアプローチなし** |
| ストーリーを時間分散＋アンケート | 10/06 決定 | 大阪は社員が休みの日に18投稿できていなかった |

「意識する」「徹底する」で終わる指示は定着しない。**判断を要らなくする／言葉を決める／記録が残る／1人が持つ** の4点を今日決める。

## ルール1「他店を見る」

**自分の意見：3つの中でこれが本命。** 根拠が一番強い。

- 41-43が揃っている型は **裏原2型・大阪3型・名古屋4型・原宿6型だけ**
- 裏原の土日クロージング **52.5%**（平日62.3%）。土日は客が多い＝サイズ要求が多様＝出せない確率が上がる
- 11月頭の入荷で穴は小さくなるが、**東京に41-43が来るのは352足だけ**なので残る

**言い方（これを渡す）**
```
×「サイズ無いですね」
○「他の店にあるか見てきますね」
   → あれば  「取れそうです。確認して連絡します」
   → なければ「入荷したら連絡しますね」＋連絡先をもらう
```

**日付は約束しない。折り返しを約束する。** 本国からは1ヶ月かかるので、日付を言わせたら嘘になる。

**この場で決めること**
- 他店から1足だけ動かせるか。動かすなら誰がどう運ぶか（東京2店はスタッフが持てる？）
- 票の置き場所（レジ横に物理的に挟む。画面管理だと見ない）
- 連絡の担当を日直にして、シフト表のどこに入れるか

### 想定問答

**「取り寄せて来なかったらクレームになる」**
→ **これが一番怖い**という認識は共有する。だから日付を約束しない設計にした。「見てきますね」「連絡します」だけ。**約束して連絡しないのが最悪**なので、連絡の担当を日直に固定して、票を物理的に目に見える場所に置く。

**「アプリの見方が分からない」**
→ 画面写真つきの手順書を1枚作る。文字だけだと使われない。

# 議題3｜自店の11月目標

## 自分の意見

**結論：各店が選ぶ数字に口は出さない。ただし形式は固定する。**

```
動かす数字 1つ ＋ そのための行動 1つ ＋ いつ測るか
```

**「売上をいくら」ではなく「どの率を何%に」で出させる。** 10/06は宣言が曖昧で、コンソールMが大阪に「数値に向けて何をするか書け」と指摘する流れになった。同じことを繰り返さない。

**予算を目標にしない。** 10月は4店で予算の45.9%（着地見込¥21.6M／予算¥47M）。予算を目標にすると最初から未達前提で動くことになる。**着地見込＋αで置く。**

## 店別に渡す材料（この表を各店に渡す）

| 店 | いちばん大きい穴 | 戻せば |
|---|---|---|
| **名古屋** | **土日**。来客が平日の2.1倍（16.8→34.8人/日）来るのに試着率が37.3→34.9%に落ちる | 土日の決定率を平日並みで**月+22.8万** |
| **大阪** | クロージング 9月70.1%→10月62.2% | +66.4万/25日 |
| **裏原** | 来客+24.8%で4店最大に増えたのに試着率・クロージング・セット率・客単価が全部下落。土日クロージング52.5% | +17.3万/25日 |
| **原宿** | 平均単価−5.9%（4店最大の下げ）。足/組1.73→1.56 | 平均単価を大阪水準で**+84.6万/25日** |

## 押さえること

- **原宿は10/06で唯一、数値目標を出していない**（立ち位置の徹底・ファーストの声かけ・ダブル接客のみ）。11月は数字で出させる
- **名古屋の土日問題は本人が気づいていない可能性が高い。** データを見せる。平日の水曜はクロージング89.5%、金曜86.4%出ている。**平日は売れている店が、人が来る土日に崩れている**
- **原宿だけ決定率を守れた**（来客+15.6%で決定率+0.7%）。何をしていたか聞いて、他店に渡す

### 想定問答

**「予算が達成不可能」**
→ **同意する。** 予算の見直しは上の判断。「予算は予算として残るが、店の目標は着地見込＋αで置きます」で通す。争わない。

**「目標を下げるのか」と上から言われたら**
→ 下げていない。**予算を分解した行動目標を初めて置く**という整理。10月は予算45.9%で、数字だけ掲げて届かなかった。

# 議題4｜来客をどう増やすか

## 自分の意見

**結論：接客だけでは11月予算に届かないことを数字で出し、集客は上の責任・接客は店の責任と切り分ける。**

これをやらないと、会が「頑張ります」で終わるか、予算批判で終わる。

## 根拠

- 着地見込 ¥21.6M ＋ 全レバー社内ベスト ¥11.0M ＝ **¥32.6M。11月予算¥48Mに¥15.4M届かない**
- 11月予算を客単価¥22,900・決定率35%で逆算すると**必要来客193人/日。今は88.3人/日（2.2倍）**

**来客は3店で増えている**（原宿+15.6% / 大阪+21.3% / 裏原+24.8%）。これは10/06で社長が言っていた「東京店の広告で来店数が約20%増加」と一致する。**広告は効いている。取りきれていないのが店側。**

→ だから順序は「まず取りきる（ルール1〜3）、その上で集客を増やす」。

## 店頭でできることとして出すもの

10/06で新宿ルミネの隣店の事例（ローテーションで通路の真ん中に立つ／アイキャッチと笑顔で足を止める）を全店に指示した。
**10/19に原宿を見たら、入口横と対をなして棒立ち2名、通りすがりへのアプローチが何もなかった。**

→ **口頭指示が定着していない実例として出す。** 立ち位置の図とローテーション表を紙にする、と宣言する。

## 宿題の形

```
店頭で自分たちでできること  …… 立ち位置、声かけ、外観
SNSに頼むこと             …… 「こういう動画が欲しい」の形で
広告に頼むこと             …… 「この型・この客層に出してほしい」の形で
```

**3つに分けないと「広告もっとやってほしい」で終わる。**

### 想定問答

**「広告をもっと回してほしい」**
→ 「回ってます。来客は3店で15〜25%増えてます。増えた分の決定率が落ちてるので、まず取りきるほうが先です」で返す。数字があるので言える。

**「人が足りない」**
→ 名古屋の土日は事実そう見える（来客が平日の2.1倍で試着率が下がる）。**シフトの厚みの話として受ける。** ただし「人を増やす」ではなく「土日に誰をどこに置くか」に落とす。
