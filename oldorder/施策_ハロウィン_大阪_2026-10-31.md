# ハロウィン企画｜大阪店・10/31(土)限定

作成 2026-10-28 ／ 店舗統括 ／ **実施まで3日**

---

# 1. この施策の目的

**来客を増やすこと。そしてフォロワーと会員を獲得すること。**

参加条件が購入ではなくフォロー＋会員登録なので、**得られる資産は売上ではなくフォロワーと会員**。
売上は副次的なものとして扱い、評価もそこではしない。

## なぜ今これをやるのか

| 事実 | 意味 |
|---|---|
| 会員セールが10/29に終わる | **10/30以降は反動の谷が来る。** そこに来店の理由を置く |
| 10/31は土曜＋ハロウィン。南堀江は人が出る | 通りすがりが多い日に、**声をかける口実**が手に入る |
| 10/20のMTGで「来店経路のヒアリング徹底」が宿題になった | **会員が増えれば来店経路が測れる。** 広告の最適化の前提 |
| 大阪の10月の来客は+19.7%（広告の効果） | 来客は伸びている。**その流れを11月に繋ぐ** |

## 層Bの景品と本数

| 等級 | 景品 | 本数 | 価額（算定後） | 小計 |
|---|---|---|---|---|
| **1等** | BBIMP Bunny Skull Lace | **1** | ¥3,474（自店販売価格） | ¥3,474 |
| **2等** | ライター（20歳以上の方のみ） | **1** | 約¥1,000 | ¥1,000 |
| **2等** | キーホルダー | **2** | 約¥300 | ¥600 |
| TRICK! | お菓子もう1個 | 多数 | 層Aの枠内 | — |
| | | **当たり4本** | | **¥5,074** |

**2等は「ライターかキーホルダーをお選びいただく」。** ただし用意はライター1本・キーホルダー2本で固定し、
POPに「**数に限りがあります**」と明記する。これで総額が確定する。

### 当選確率

```
参加想定 25人（来客36組 × 参加率60〜70%）
当たり 4本 → 当選率 16%
```

**1〜2本だと盛り上がらず、半分当たると特別感が消える。15〜25%が適正。**

## くじの形式：ルーレットではなく「くじ箱」を推奨

| | 本数管理 | 盛り上がり |
|---|---|---|
| ルーレット | **出た数だけ渡すことになり、本数を超える危険がある** | ◎ 回す動作が映える |
| **くじ箱（推奨）** | **1等1枚・2等3枚・TRICK!多数で物理的に超えない** | ○ |

**総額規制があるので、本数を超えないことが優先。**
ルーレットでやるなら、当たりが出きった時点でその面を物理的に塞ぐ運用が必須。

くじ箱にするなら、**ハロウィンらしい見た目のかぼちゃ型の箱や黒い紙袋**にすれば撮影映えは確保できる。

## 獲得単価で見る

```
フォロワー2アカウント ＋ 会員登録 を 1人あたり ¥114〜¥210 で獲得
来客 +6組なら 1組あたり ¥873
```

Instagram広告のフォロワー獲得単価より安い。**景品原価は負担にならない。**

## 本当のコストはスタッフの時間

```
フォロー確認 ＋ 会員登録の案内  1人あたり 3〜5分
参加25人 × 4分 = 約1.7時間
```

**土曜は来客30組・試着率71.7%で元々忙しい。** ここが実質的な負担。

対策：**入口のお菓子は10秒で渡す。くじの案内は接客が一段落した時点かレジで。**
試着中のお客様を中断させない。会員登録はタブレットを1台専用にしてスタッフが待たない。

## 売上はおまけ（期待しない）

購入が増えなくても損失は¥5,240。
大阪の粗利率は84.3%なので、**購入が1組増えれば粗利¥19,300。原価の3.7倍。**
ただし**これは目的ではないので、評価指標に入れない。**

# 4. 来客を増やす +α（景品より効く）

**来客は「企画の中身」より「知られているか」と「入りやすいか」で決まる。**
景品設計に時間をかけるより、以下に時間を使ったほうが来客は動く。

## 前提：くじの当たり本数は4本で固定

総額規制があるので当たりは増やせない。
**だが「くじを2回引ける」という+αは、当たり本数が変わらないので総額に一切影響しない。**
タダで参加動機を足せる。

## ① 既存会員にメール／LINEで直接配信する ← 最優先

**Instagramの投稿は既存フォロワーにしか届かない。**
来客を増やすなら、**すでに名簿がある人を呼び戻す**のが最も確実。

10/20のMTGで「[金子ゆき] 名古屋顧客メール配信：名古屋の顧客情報をもとに招待メールの配信」が
宿題になっている。**顧客配信の仕組みは既にある。**

→ **大阪の会員にメール／LINEで10/31の案内を送る。コストゼロ。**

しかもこれは**会員登録の価値を証明する**ことになる。
「登録したら案内が来る」が成立すれば、当日の会員登録の説得力も上がる。

**配信文（そのまま使える）**

```
件名：10/31(土) ハロウィン｜大阪店でお菓子とくじをご用意しました

いつもありがとうございます。OLD ORDER 大阪店です。

10/31(土) の1日限定で、ご来店の方にお菓子をお渡しします。
インスタ2つのフォローと会員登録で、ハロウィンくじも1回引けます。

1等  BBIMP アクセサリー
2等  ライター or キーホルダー

仮装でのご来店は くじ2回。
18時以降のご来店も くじ2回です。

当日ご来店の方限定です。お待ちしています。

※景品は数に限りがあります
※ライターは20歳以上の方に限ります
```

## ② 複数アカウントから告知する

大阪店アカウント単独ではリーチが天井にぶつかる。

```
・OLD ORDER 本アカウント
・OLD ORDER styling
・EC アカウント
・他店アカウント（原宿・裏原・名古屋）から「大阪でやってます」
```

**コストゼロでリーチが数倍になる。** SNS統括に依頼する。

## ③ 装飾を告知に使う（装飾は実施済み）

**店前の装飾はすでに進んでいる。これを撮ってSNSに出さないと投資が無駄になる。**

```
10/30 夜    装飾の写真でフィード投稿（「明日やります」）
10/31 開店前 装飾＋スタッフの写真でストーリー
```

装飾があると**店前に人を立てる価値が上がる。**
装飾で足が止まった人に「お菓子どうぞ」と声をかけられる。

**お菓子はカゴに山盛りにして店前に置く。** 「お菓子どうぞ」と言う前に、見ただけで伝わる状態を作る。

## ④ 仮装で来店＝くじ2回（コストゼロ）

```
仮装でご来店の方は くじ2回
```

- **当たり本数は4本のままなので総額に影響しない**
- ハロウィンらしさが店頭に出る → 通行人の目に留まる
- 許可をもらって撮影 → そのままSNSコンテンツになる（顔は映さない or 許可を取る）

## ⑤ 18時以降の来店＝くじ2回（来店時間の分散）

土曜は来客30組。**夕方に寄せると、日中に来られない人の来店理由になる。**
これもコストゼロ。

**ただしスタッフの手が夕方に集中する。** 人員配置と合わせて判断する。

## ⑥ 近隣店にお菓子を配る

南堀江は服屋が集まるエリアで、10/31は各店が何かやる。
**近隣店のスタッフにお菓子を持っていくだけ**で、口コミと相互送客のきっかけになる。

3日でスタンプラリーのような連携は組めないが、挨拶レベルなら今日からできる。

## 注意が必要なもの

**スタッフの個人アカウントからの告知**
リーチは広がるが、**スタッフが自社の宣伝を個人アカウントでやると、
景表法のステマ規制で「事業者の表示」に該当しうる。**
やるなら「勤務先です」等の明示が必要。店の公式アカウントからの発信なら明示は不要。

## やらないほうがいいもの

| | 理由 |
|---|---|
| **値引き** | 会員セールが10/29に終わったばかり。**2日後にまた値引くとセールの価値が落ちる** |
| **新規の広告出稿** | 3日では審査と最適化が回らない。ただし**既存の大阪の広告クリエイティブをハロウィン告知に差し替える**のは可能性がある（津田さんに確認） |

## +αの優先順位

| | +α | コスト | 誰が | 状態 |
|---|---|---|---|---|
| 1 | **既存会員にメール／LINE配信** | ゼロ | 要確認（配信の仕組みを持つ人） | **未着手・最優先** |
| 2 | **複数アカウントから告知** | ゼロ | SNS統括 | 未着手 |
| 3 | 装飾を告知に使う | ゼロ | 大阪店 | **装飾は実施済み。撮影と投稿が未着手** |
| 4 | 仮装で来店＝くじ2回 | ゼロ | 大阪店 | POPと告知に反映すれば完了 |
| 5 | 18時以降＝くじ2回 | ゼロ | 大阪店 | 人員配置と合わせて判断 |
| 6 | 近隣店にお菓子 | 数百円 | 大阪店 | 任意 |

# 10. 法的な整理

| 論点 | 判定 | 根拠 | 内容 |
|---|---|---|---|
| 来店者（購入不要）のくじ | **白** | 懸賞制限告示（昭52公取委告示3号）／懸賞運用基準 | 来店を条件とする提供は取引付随性があり景品規制の対象。**取引価額は原則100円だが、当該店舗で通常行われる取引の最低価額が100円を超えるときはその価額**。大阪店の10月の実売で最も安い商品は **Logo Socks ¥504** なので、**上限は ¥504 × 20 = ¥10,080**。1等BBIMP ¥3,474 は収まる |
| 懸賞の総額 | **白** | 同上 | 懸賞に係る売上予定総額の**2%**。10/31の売上予定¥316,000なら**約¥6,300**。景品総額は**¥5,074**で収まる |
