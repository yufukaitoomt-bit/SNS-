## 【重要・2026/10/14 判明】スマレジの「部門名」は機種名ではない

在庫一覧・商品別売上CSVの **部門名は機種（モデル）ではなく、その上のくくり**。
機種名は **商品名から取り出す**しかない（`品番`列は全2,375行すべて空）。

抽出方法：商品名から先頭の `【ブランド】` を除き、末尾の ` / カラー` を除いた残り。

| 部門名 | 中に入っている機種 |
|---|---|
| OCAI | DISK RUNNER(54) / RETRO 001(52) / **Smile Canvas**(23) / Speed Car(15) |
| CANVAS | Canvas(34) / **Smile O Canvas**(22) / Canvas Tweed(15) / Comic Denim Canvas(11) |
| BBIMP | QBoots など |
| CANVAS CHAOS | **HIGH と LOW** |
| Turbo GT | Turbo GT のみ（一致） |

### これの影響

- **統合資料 Part 2-4／Part 7-8 の消化率は部門単位なので、機種が混ざっている**。読み替えが必要
- 現場（10/13 MTG）は機種名で話している：「ディスクランナー」=DISK RUNNER、「ランテック」=Runtech 3.0、「カオスのハイ/ロー」=CANVAS CHAOS HIGH/LOW、「スマイル」=Smile Canvas
- **機種単位にすると結論が変わる例**

| | 部門単位の見え方 | 機種単位の実際 |
|---|---|---|
| CANVAS CHAOS | 消化率44.1%・在庫409点 | **HIGH 64.0%・在庫82点** ／ **LOW 34.7%・在庫311点** |
| スマイル | OCAI/CANVAS部門に埋没 | **Smile Canvas 販売1,281点・売上¥30,093,711・消化率83.3%＝全社2位の売れ筋** |
| OCAI 74.8% | 1つの品番のように見える | DISK RUNNER 61.2% ／ Smile Canvas 83.3% ／ RETRO 001 64.4% が混在 |

→ **今後の在庫分析は機種単位で出す。** 部門単位は使わない。
→ 名古屋のVMDは「カオスを面で」ではなく「**カオス LOW を面で**」が正しい（HIGHは在庫82点で尽きる）

## 10/13 MTG の結果（Geminiメモより）

**「今日決めること」10項目は1つも決まらなかった。** 決定事項として残ったのは3件のみ。

| 区分 | 内容 |
|---|---|
| 調整済み | 売れ筋商品の代替商品の把握徹底 → **10/20の配布資料として形にした** |

| 要継続議論 | 名古屋店の動線改善（通路を在庫で潰す案）→ 後日ビデオ通話 |

### 原因と対策

- 「各店4分の型」は機能せず、**テーマ別の横断議論に自然に変わっていた**。その方が議論は深いので、10/20はテーマ別を前提に組む
