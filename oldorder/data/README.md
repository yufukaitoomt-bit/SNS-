# データ置き場

分析の元データを蓄積する場所。**同じ形式で毎月もらえば、月次推移が追えます。**

## 免税_国籍別_YYYY-MM

海外のお客様の国籍と購買データ（免税手続きをした取引のみ）。

| | |
|---|---|
| 形式 | xlsx（原本）＋ csv（正規化したもの） |
| 必要なシート | **集計対象DATA**（店舗名・譲渡日・国籍・国名・全体合計額(税抜)・購入金額） |
| 他のシート | 店舗別国籍割合DATA／国別平均購買単価DATA／店舗別国籍件数DATA（集計対象DATAから再計算できるので無くても可） |

### ⚠ この数字が表しているもの

**免税手続きをした取引だけです。** 免税しなかった海外のお客様は入りません。
「海外客の全体像」ではなく「**免税客の国籍構成**」として読んでください。

## 免税_明細_YYYY-MM

免税販売一覧（47列）を**匿名化した**もの。品名・性別・年代・上陸日・時刻が入っている。

| | |
|---|---|
| 形式 | csv（匿名化済み） |
| 列 | 店舗名・譲渡日・時刻・性別・年代・国籍コード・国名・来日何日目・JANコード・品名・数量・販売価額・全体合計額(税抜)・免税手数料 |

### ⚠ 個人情報

原本には **氏名・旅券番号・生年月日・オペレータID** が含まれます。
**原本はリポジトリに保存しません。** 生年月日は年代に変換したうえで CSV 化しています。

### ⚠ 品名欄の制約

**品名欄には取引明細の1行目しか出ていません。**
- 178件中139件が複数購入で、2行目以降の商品は分かりません（金額ベースで¥981,398が未紐付け）
- 30件は**ショッパー（紙袋）が1行目**に来ているため、靴が分かりません
- 売れ筋集計に使えるのは **148件**

### 蓄積の状況

| 月 | 件数 | 免税売上 | 平均単価 | 免税比率（3店） |
|---|---|---|---|---|
| 2026-09 | 178 | ¥3,806,716 | ¥21,386 | 18.5%（裏原30.4 / 原宿21.0 / 名古屋7.5） |

### 欲しいもの（揃うと出せる分析が増えます）

- **毎月1本**（月次推移・前年比が出せる）
- 各店の**購入人数**（免税比率が出せる。今は件数しか分からない）
- 可能なら**購入した商品**（国籍別の売れ筋が出せる）
