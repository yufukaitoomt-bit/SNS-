# データ置き場

分析の元データを蓄積する場所。**同じ形式で毎月もらえば、月次推移が追えます。**

## 免税_国籍別_YYYY-MM

海外のお客様の国籍と購買データ（免税手続きをした取引のみ）。

| | |
|---|---|
| 形式 | xlsx（原本）＋ csv（正規化したもの） |
| 必要なシート | **集計対象DATA**（店舗名・譲渡日・国籍・国名・全体合計額(税抜)・購入金額） |
| 他のシート | 店舗別国籍割合DATA／国別平均購買単価DATA／店舗別国籍件数DATA（集計対象DATAから再計算できるので無くても可） |

### ⚠ この数字が表しているもの

**免税手続きをした取引だけです。** 免税しなかった海外のお客様は入りません。
「海外客の全体像」ではなく「**免税客の国籍構成**」として読んでください。

## 免税_明細_YYYY-MM

免税販売一覧（47列）を**匿名化した**もの。品名・性別・年代・上陸日・時刻が入っている。

| | |
|---|---|
| 形式 | csv（匿名化済み） |
| 列 | 店舗名・譲渡日・時刻・性別・年代・国籍コード・国名・来日何日目・JANコード・品名・数量・販売価額・全体合計額(税抜)・免税手数料 |

### ⚠ 個人情報

原本には **氏名・旅券番号・生年月日・オペレータID** が含まれます。
**原本はリポジトリに保存しません。** 生年月日は年代に変換したうえで CSV 化しています。

### ⚠ 品名欄の制約

**品名欄には取引明細の1行目しか出ていません。**
- 178件中139件が複数購入で、2行目以降の商品は分かりません（金額ベースで¥981,398が未紐付け）
- 30件は**ショッパー（紙袋）が1行目**に来ているため、靴が分かりません
- 売れ筋集計に使えるのは **148件**

### 蓄積の状況

| 月 | 件数 | 免税売上 | 平均単価 | 売上に占める割合 |
|---|---|---|---|---|
| 2026-09（全月） | 178 | ¥3,806,716 | ¥21,386 | 18.5%（件数比 19.9%） |
| 2026-10（10/1-10/16） | 150 | ¥3,286,159 | ¥21,908 | **29.8%**（10/1-10/12で算出） |

**10月は1日あたり1.58倍に加速。** 店別は 原宿2.06倍 / 裏原1.61倍 / 大阪1.29倍 / **名古屋0.38倍（激減）**。

### 欲しいもの（揃うと出せる分析が増えます）

- **毎月1本**（月次推移・前年比が出せる）
- 各店の**購入人数**（免税比率が出せる。今は件数しか分からない）
- 可能なら**購入した商品**（国籍別の売れ筋が出せる）

## 商品別売上/（店舗別・期間別）

スマレジ「商品別売上」を**店舗を絞って**出力したもの。SKU単位で 販売点数・純売上・在庫数 が入る。

| | |
|---|---|
| 形式 | csv（UTF-8 BOM） |
| 命名 | `{店名}_{30日|90日}_{開始}-{終了}.csv` |
| 主な列 | 商品コード・商品名・カラー・サイズ・販売点数・純売上・在庫数 |

### ★店舗別エクスポートは「その店の在庫数」を持ちます

90日ファイルの在庫数と各店在庫一覧の一致率：名古屋93% / 大阪87% / 原宿81% / 裏原82%。
全店在庫一覧とは16〜25%しか一致しません。→ **店別の消化率が出せます。**

### なぜ30日と90日の2本なのか

**90日販売 ÷ 30日販売** で「新作か死に筋か」を判定できます。

| 比率 | 意味 |
|---|---|
| 1.0〜1.6 | 直近30日に集中 ＝ **新作の立ち上がり** |
| 1.6〜2.4 | 伸びている |
| 2.4〜3.6 | 90日ずっと同ペース ＝ 定番 |
| 3.6以上 | 減速（昔売れていた） |

**13ヶ月の消化率だけでは、発売したばかりの商品が「死に筋」に見えてしまいます。** この2本で切り分けます。
**※ 販売10点未満の機種では比率が当てになりません。**

### ⚠ 商品名から機種を取る必要があります

**部門名 ≠ 機種名**です。品番列は空。機種は商品名を `【...】` 削除 → ` / ` 以降削除 で取ります。

```
【Ocai】Armored Football Shoes / Black  →  Armored Football Shoes
```

## 客層/（店舗別・年代／流入経路）

スマレジ「客層別売上」。レジで登録された客層IDごとの売上。

| | |
|---|---|
| 形式 | csv（UTF-8 BOM） |
| 命名 | `{店名}_{年代|流入経路}_{開始}-{終了}.csv` |
| 列 | 客層ID・ラベル・純売上・純売上(税抜)・消費税・純売上構成比・販売点数・返品数・販売点数構成比・客数・客単価 |

**ファイルに店舗名は入りません。** 合計行（純売上・販売点数・客数）を同期間の商品別売上と突き合わせて店舗を特定します。

### ⚠ この数字の制約

**客層はレジでスタッフが選んで登録する項目です。** 「通りすがり」が多い店は、本当に通りすがりが多いのか、**聞かずに既定値を選んでいるのか区別できません。**
→ **4店の「通りすがり」比率を比べることで、聞き方の差として読めます。**

### 客数は「購入人数」です

販売点数 ÷ 客数 ＝ セット率 になります（大阪30日：278 ÷ 251 ＝ 1.11）。**来客数ではありません。**
