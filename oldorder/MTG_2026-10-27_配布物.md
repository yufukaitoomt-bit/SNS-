# 11月の3つのルール

```
ルール1「他店を見る」    サイズが無いときは他店在庫を確認する
ルール2「レジでもう1つ」  購入が決まったら必ずもう1点出す
ルール3「試着は2足から」  試着は最初から2足持っていく
```

開始：**11月1日（日）**

---

## ルール1「他店を見る」

### 言い方

```
×「サイズ無いですね」

○「他の店にあるか見てきますね」
    ├─ あれば   「取れそうです。確認してご連絡します」
    └─ なければ 「入荷したらご連絡しますね」＋ お名前と連絡先
```

### 大事なこと

- **届く日付は言わない。** 「連絡します」で止める
- 本国からの補充は1ヶ月かかります。**「取り寄せます」と言っていいのは他店にある場合だけ**
- **約束して連絡しないのが一番だめ**。連絡は日直が持つ

### 流れ

```
1. アプリで他店在庫を確認
2. 票を書く（他店にある → 取り置き票 ／ どこにもない → 入荷連絡票）
3. 票はレジ横のクリップに挟む
4. 日直が連絡 → 連絡したら票にチェック
5. お渡し済みになったら票を外す
```

---

## ルール2「レジでもう1つ」

購入が決まった**直後**に、決めてあるものを1点出す。

試着中ではなく、**レジで決まってから**。断られても接客は終わっているのでリスクがない。

店ごとに出すものは下のページに。

---

## ルール3「試着は2足から」

### 言い方

```
○「比べたほうが分かりやすいので、もう1足持ってきますね」
```

### 大事なこと

- **2足目は「そのお客様のサイズがある型」から選ぶ**。サイズがない型を2足目にすると逆効果
- 1足目を出した人が2足目も出す
- 店ごとのペアは下のページに

### 正直なところ

**このルールが効くかは、まだ分かっていません。**

4店のデータでは「1組あたり何足履かせたか」とクロージング（試着した方が買う率）に、はっきりした関係が出ていません。名古屋は9月に1組1.46足で、クロージング80.4%（4店で一番高い）を出していました。

**なので11月は測ります。** 試着ログで「2足出したとき」と「1足のとき」の差を見て、効いていなければやめます。

### 結果の書き方（記号でOK）

```
購入      → ○
取り寄せ受注 → 取
入荷連絡の受付 → 連
サイズが無くて帰られた → ×サ
値段で帰られた      → ×値
迷って帰られた      → ×迷
その他で帰られた    → ×他
```

### 「サイズが無くて帰られた」ときは、型とサイズを必ず書いてください

**これが11月の発注と、店舗間の在庫移動の根拠になります。** 書いた分だけ在庫が動きます。

### この紙から出る数字（週1回、統括から返します）

- 取り寄せを提案できた率
- 2足出せた率
- 2足のときと1足のときのクロージングの差
- 帰られた理由の内訳
- サイズが足りていない型とサイズ
