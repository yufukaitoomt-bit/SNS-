# 0. 先に警告：**この数字を、人の評価に使わないでください**

右腕から来た数字：

```
10/01 木 原宿  8.0%  （来客25人・購入2人）
10/09 金 原宿 11.5%  （来客26人・購入3人）
10/10 土 原宿 55.2%  （来客58人・購入32人）
```

## 「5倍違う」は、煽りすぎ

**1日の来客数では、決定率はそもそも激しくブレます。** 実力が同じでも。

| 1日の来客 | 真の実力が35%でも、95%で起こりうる範囲 |
|---|---|
| 25人 | **20.2% 〜 55.5%**（幅35pt） |
| 58人 | 23.6% 〜 47.3%（幅24pt） |
| 150人 | 27.5% 〜 42.6%（幅15pt） |
| 650人（4店・週） | 31.4% 〜 38.7%（幅7pt） |

**来客25人の日の決定率は、ほぼ何も意味しません。**
店長会資料が警告している「暇な日の極端な%に引っ張られる」の、日別版です。

> ⚠ 来客10人の日と来客44人の日が同じ1票になるので、暇な日の極端な%に引っ張られます（店長会 Part1）

→ **日別決定率を個人に紐づけて平均する手法は、原理的に使えません。**
　 右腕が「全員31〜43%に収まった」のは、**手法の限界**であって、全員同じという結論ではない。

## ただし、この2日だけは本当に異常です

真の実力が35%だと仮定したとき、

| | 起こる確率 |
|---|---|
| 10/01 木：25人中2人以下 | **0.21%** |
| 10/09 金：26人中3人以下 | **0.70%** |

**偶然では説明しにくい。** この2日は、何かあったはずです。

### ★ でも「誰が」ではなく「何が」を聞く

ここが分かれ目です。

```
❌ 「10/1と10/9、誰が入ってた?」     → 犯人探し。場が終わる
✅ 「10/1と10/9、なんかありました?」  → 事実確認。情報が出る
```

**この2日は、本音会の一番いい入口になります。**
人を責めない形で、具体的な話から始められる。

# ① 今日のうちに使う「空気感の聞き方」

## 原則：**人ではなく、場面を聞く**

これは接客分析で出た構造とまったく同じです。

```
観察 → 仮説 → 短い質問ひとつで確認
```

「不満ある?」は、接客の「何かお探しですか?」と同じ。
**構えられて終わるか、愚痴大会になるかのどちらか。**

## 今日、個別に聞く質問（3つだけ）

> **1.「最近、接客で一番やりにくかった場面ってどんなん?」**
> **2.「これさえ無かったらもっと売れるのに、ってある?」**
> **3.「お客さんに言われて困ったこと、最近あった?」**

**全部「場面」を聞いています。** 人の話は、場面の話から勝手に出てきます。
そして出てこなければ、それは人の問題ではないということ。

## 今日やってはいけない

| | なぜ |
|---|---|
| 「〇〇さん（代理）どう?」と直接聞く | 言った方も聞いた方も、もう戻れない |
| 「不満ある?」 | 構えられる。本音は出ない |
| その場で何かを約束する | 今日は**取る日**。返すのは明日 |
| 代理や前店長の処遇を匂わせる | 噂が先に回って、明日が終わる |

## 聞く順番

**一番おとなしい人から。**
声の大きい人から聞くと、その人の意見が「店の空気」として海登さんの頭に先に入ります。

# ② 明日の本音会 ── 進行表

## 前提の4つ（右腕の指摘。そのまま採用）

1. **店長代理に仕切らせない。** 的になっている人が司会をすると吊るし上げになる
2. **扱う範囲を絞る。** 人事と待遇は today 扱わない
3. **全員に順番に同じ質問。** 挙手制だと声の大きい人の意見が全体の意見に見える
4. **その場で決めず、期限を切って必ず返す**

## ★ 追加で、一番効くと思うこと：**冒頭で事実を開示する**

**文句の半分は「知らされていない」から出ます。**

現場がたぶん知らない事実：

| | |
|---|---|
| 入荷 | 10/20頃に約3,000足。**中国の休みで11月にずれる可能性** |
| 中身 | **薄底がほとんど。厚底の40以上は入ってこない** |
| Turbo GT White Silver 40〜43 | **今回も入らない**（現に全滅中） |
| 検品 | 倉庫1人・1日1,000足が上限。**3,000足で3日** |
| 在庫数 | **マイナス在庫20SKU・-1,815点。数が信用できない状態** |

これを先に渡すと、
**「なんで売れないんだ」が「じゃあこの条件でどうするか」に変わります。**

隠したまま企画の話をすると、「また現場を知らない企画か」になる。
実際、**在庫が壊れている状態で企画を出されたら、文句が出るのは正常な反応**です。

## 進行（60分想定）

| | 時間 | 内容 |
|---|---|---|
| **0** | 5分 | **何を決める会か／決めない会かを最初に言う**<br>「今日は人事の話はしません。明日から変えられることだけ」 |
| **1** | 10分 | **事実の開示**（上の表）。質問は受けるが議論はしない |
| **2** | 20分 | **全員に順番、同じ質問をひとつ**<br>「**今、一番やりにくいことを1つ**」<br>・一人3分。遮らない。反論しない。**メモだけ取る**<br>・おとなしい人から順に |
| **3** | 15分 | **その場で3つに分類するだけ**（解決しない）<br>　🟢 明日から変えられる<br>　🟡 調べて返す（期限を言う）<br>　🔴 今は変えられない（**理由をその場で言う**） |
| **4** | 10分 | **期限を切る**<br>「🟡は〇日までに返します」「🟢は明日から」 |

## 「今、一番やりにくいことを1つ」が本体です

- **「不満」と言わない。** やりにくいこと、と言う
- **1つに絞らせる。** 絞ると、本当に効いているものが出る
- **全員に同じ質問。** 比べられる形になる

## 🔴 を言う勇気が、この会の信用を決めます

「できません、理由はこれです」と**その場で言い切る**。
持ち帰って曖昧にするのが一番悪い。**言わせたのに何も返ってこない**のが、本音会が死ぬ理由。

# ③ 「不満があるスタッフは辞めた方がいい」への見解

## 半分同意します

腐らせる人が1人いるコストは、人が1人減るコストより高い。これは事実です。
裏原は来客97〜158人と少なく手が足りていませんが、**それでも腐敗の方が高くつく**ことはあります。

## でも、この括り方は危ないです

### 理由1：「不満」で切ると、残るのは「言わない人」

言わない人だけの店は、**問題が見えなくなります。**
今まさに本音会をやろうとしているのは、見えていないからのはずです。

### 理由2：今、現場には**言うべき正当な事実**がある

- 売れ筋が全滅していて、次の入荷でも入らない
- 在庫数が信用できない（-1,815点）
- 予算が¥47M と ¥60M で食い違っている

**この状態で企画が降りてきたら、文句が出るのは正常です。**
それを言っている人を「不満分子」で括ると、**一番よく見ている人を失います。**

### 理由3：タイミングが最悪になる

右腕の指摘が正しいです。
**本音会の翌日に人が辞めると「本音を言ったら切られた」と伝わります。**
その店で本音会という手段が、二度と使えなくなる。

→ **本音会と人事を、最低2週間は離してください。**

---

## 分け方の提案

**「不満を言うか言わないか」ではなく、2軸で見る。**

| | |
|---|---|
| **軸1** | **事実を言っているか／人を攻撃しているか** |
| **軸2** | **自分の持ち場で手を動かしているか／言うだけか** |

```
事実を言う ＋ 手を動かす  → 一番大事な人。絶対に失わない
事実を言う ＋ 動かさない  → 動かし方を教える。まだ使える
人を攻撃   ＋ 手を動かす  → 言い方を正す。本人に直接言う
人を攻撃   ＋ 動かさない  → ここだけが対象
```

**「不満」は基準にならない。「事実かどうか」と「動いているか」が基準になります。**

## 人事そのものについて

### 前店長（「また店長をやりたい」）

**勤怠という客観基準がある以上、これは一番簡単なケースです。**

「不満があるから」ではなく「**当欠と遅刻があるから**」で説明がつきます。
恣意的に見えないし、本人も反論しにくい。

> 「店長は勤怠が条件。〇ヶ月、当欠・遅刻ゼロなら改めて話す」

**基準を先に示して、戻る道を残す。** 切るのではなく、条件にする。

※ 石谷さんの「G→欠」2回（10/5・10/10）も、同じ枠で扱える話です。
　 ただし記録が正しいか、本人の事情を聞いてから。

### 店長代理（「降りたい」）

**聞くべきは「何を言われたか」です。**

- **代理個人への批判**（判断が遅い、指示が曖昧 等）→ 本人の課題。直せる
- **代理が決められないことへの不満**（在庫、企画、予算）→ **代理は避雷針になっているだけ**

後者なら、代理を替えても次の人が同じ目に遭います。**人の問題ではない。**

そして海登さんの方針（代理を継続させたい）を通すなら、
**代理が決められる範囲を広げるか、決められないことは海登さんが前に出て引き受ける**しかありません。

**「代理だから決められない」まま矢面に立たせるのが、一番もたない形です。**
