# 統括の接客の構造分解

> 作成：2026-10-19
> 対象：2026-10-12〜10-14 の4件（すべて大阪）
> ※ n=4、自己記録。構造の抽出が目的で、効果の証明ではない。

---

## 結論：5段のエンジンで動いている

```
⓪ 来店直後に必ず声をかける → そして引く   ← 質問はしない
        ↓
① 間を空けて観察し、仮説を立てる
        ↓
② 短い質問ひとつで仮説を確認する          ← ここで「軸」が決まる
        ↓
③ 軸に沿って、現物を足に乗せ続ける
        ↓
④ 比較を作り、優劣を言わずに選ばせる／押して、引き際で引く
```

**この5段が回っている時は全件成約している。止まった1件だけが失注。**

---

# ⓪ 来店直後に必ず声をかける ── ただし質問ではない

**例外なく、入店直後に声をかけている。**

> 挨拶 ＋ **「サイズも出すんで、なんでも言ってください」**

10/14 のメモにそのまま出ている：
> 「入ってすぐにファースト（あいさつは、どこから来たの?）」→ **「少し時間空けて」**

## この一言が同時に4つやっている

| | |
|---|---|
| **質問ではない** | 「いえ、大丈夫です」という断りが発生しない |
| **「サイズも出す」** | 試着のハードルを、接触の最初で先に下げている |
| **「なんでも言ってください」** | 客から声をかける行為を正当化している |
| **言い切って、引く** | 間が生まれ、客が自分で動き出す → ①の観察が成立する |

## 店長会「言ってはいけない言葉」との照合

| 店長会 ✕ | この人 |
|---|---|
| 「何かお探しですか」 | **言っていない** ✅ |
| 「ご試着できますよ」→ ○「サイズ出してきますね」（断定して動く） | **「サイズも出すんで」＝宣言形** ✅ |
| 「ゆっくり見ていってください」 | **「なんでも言ってください」** |

最後の1つは似ているが性質が違う。
**「ゆっくり見て」は距離を置く宣言。「なんでも言って」は接点を残す宣言。**

また、店長会 2-1（新宿ルミネの他店事例）で共有された
「**気になるものあったらいつでも言ってください**」と、ほぼ同じことを既にやっている。

## ★ そして、ここが ④ と同じ形をしている

```
入口 ： 声をかける → 引く（間を空ける）→ 客が自分で動く → 観察できる
出口 ： 押す       → 引く（引き際）    → 客が自分で決める → 戻ってくる
```

> **「出して、引く」が、この人の基本動作。** 接客の最初と最後に同じ形が出ている。

渡すものを渡したら、**判断は客に返す。** それを両端でやっている。

# ① 間を空けて観察し、仮説を立てる

⓪で声をかけた後、**追わずに間を空けている。**
そして最初に取る情報は、質問の答えではなく**行動**。

| 接客 | 何を見たか | 立てた仮説 |
|---|---|---|
| 10/12 カップル | 声かけ後に一周させ、SMILE で足が止まった | これが本命 |
| 10/13 Brunch | 声かけ後に一周させ、**Brunch を2回目に手に取った** | ここが本気 |
| 10/13 団体 | **薄底ゾーンにいる** | この価格帯・この系統 |
| 10/14 メキシコ | 声かけ後に間を空け、**白系を触ることが多い** | 白が好き |

### 特に 10/13 Brunch の「2回目」

「足を止めた」ではなく「**一度置いて、また手に取った**」で入っている。
シグナルの精度が一段高い。

### なぜこれが効くのか

**行動は嘘をつかないし、言葉がいらない。**

4件中3件が海外客（うち2件は英語も通じない）。
**質問で情報を取りにいく型なら、この3件は全部崩れていた。**

そして ⓪ で「なんでも言ってください」と接点を残しているので、
**間を空けても放置にならない。** 観察の時間が、客にとっては自由に見る時間になっている。

# ② 短い質問で仮説を確認する ── ここで「軸」が決まる

観察で立てた仮説を、**1つの短い質問で確認している。**

| 接客 | 質問 | 結果 |
|---|---|---|
| 10/12 | 「**普段どんな服着るんですか?**」 | カジュアル／細身のパンツ |
| 10/14 | 「**白が好きですか?**」 | **的中** |
| 10/13 団体 | 「どんなものを履くのか／何を探しているのか」 | DIVISION／ネイビー／シルバー系 |

**質問は情報収集ではなく、仮説の答え合わせ。** だから1つで済む。

### そして、軸は最後まで持ち続ける

```
10/14： 「白」を確認 → DiskRunner 白 を試着 → 一度出る → 白 を買いに戻る
10/12： 「カジュアル」→ 普通のキャンバスよりスタッズの方が合わせやすい
10/13 Brunch： 「茶色」が欠品 → 色の軸を広げて「別カラーでも似合う」
```

**商品が変わっても、軸は変えない。**

10/13 団体だけは例外で、**途中で軸を切り替えている**（下記④参照）。

# ④ 比較を作り、優劣を言わずに選ばせる／押して、引き際で引く

## 決め方のパターンが3種類ある

### (a) 両方に役割を与える（10/13 団体）

> 「**黒はコーデに馴染む。ネイビーは少し外しっぽい感じで使えるよ**」

**「黒の方がいい」とは言っていない。** 場面を2つ渡して、客が選ぶ。
しかも選ばなかったネイビーを否定していないので、**次の一足への伏線**になる。

### (b) 断定で不安を切る（10/13 Brunch）

サイズを3回変えても決まらない相手に、
> 「**似合ってる**」「**素材**」「**かわいい**」

サイズの話を続けても解決しない。**迷いの正体は「本当にこれでいいのか」という不安**で、
断定がそれを切っている。

### (c) 押して、引き際で引く（10/14）

```
押す：「進化系」「人気」／取り置きの提案
引く：「考える」と言われた時点で止めた
→ 1時間半後、笑顔で戻って購入
```

**押しがなければ持ち帰る材料がない。引き際がなければ戻れない。**
押し売り感を生むのは「押したこと」ではなく「引かなかったこと」。

## 軸を切り替える判断（10/13 団体）

この回だけ、**途中で軸を切り替えている。**

```
客の希望： DIVISION ／ ネイビー ／ シルバー系
   ↓ 全部に現物で答えた（3足）
   ↓ それでも決まらない
軸を切替： 「今日の半ズボン」ではなく「普段の長ズボン」
   ↓ デニムを持ってきて鏡の前で合わせる
結果：    当初の希望と違う「黒」を購入
```

**客が口にした希望を全部潰した上で、別の軸を出している。**
希望を無視したのでも、希望に縛られたのでもない。

# 弱点 ── エンジンが止まる3箇所

## 🔴 弱点1：連れに対して ①② が回っていない

複数客2件で、**結果が分かれている。**

| | 連れへの提案 | 連れの試着 | 結果 |
|---|---|---|---|
| 10/12 | 「シミラーで合わせたら可愛い」 | 2回 | 再試着まで戻せた |
| 10/13 Brunch | **なし**（同じものを出しただけ） | 1回 | **非購入** |

本人に対しては観察→仮説→確認を回しているが、**連れには回していない。**
連れは「一人目と同じものを出される人」になっている。

→ **一人目が決まった瞬間が、連れへの①の開始点。**

## 🔴 弱点2：③の途中で中断することがある（致命的）

10/12、白37がジャストで決まった**直後に、リボンを探しに離席**。

**4件で唯一、構造から外れた行動。** そしてこの1件だけが失注。

- 引いたのではなく、**勝手に中断した**
- 客の意識が「買うか」→「他に何かないか」に移った
- 戻った時には、欲しいものが在庫のない黒37に書き換わっていた

→ **押しが途切れるのと、引き際で引くのは別物。**

## 🟡 弱点3：軸に「時間・荷物」が入っていない

10/14、「**寄り道で来た**」が分かったのは接客の最後。

この人の軸はいつも**好み（色・系統・用途）**で、**状況（滞在時間・荷物・移動）**が入らない。

結果的には成約したが、最初に分かっていれば組み立てが変わった。
※ 取らなくても成約しているので、必須とまでは言えない。

# 掲示フローとの構造的な違い

| | 掲示フロー | この人 |
|---|---|---|
| 最初の一言 | **「初めてですか?」＝質問** | **「サイズも出すんで、なんでも言ってください」＝宣言** |
| その後 | そのまま質問を続けて絞り込む | **引く。間を空けて観察する** |
| 質問の役割 | 情報を取る | **仮説の確認（1つで済む）** |
| 共通ルール | 「いきなり商品提案に行かず、**先に情報を取り**、的を絞る」 | **先に見て、的を絞ってから1つ聞く** |
| 決め方 | 褒めた後に「**決め手を1つ**」 | **両方に役割を与えて選ばせる**／断定／押して引く |

**どちらが正しいかではなく、別の型。**

決定的な違いは**最初の一言が質問か宣言か**で、そこから全部枝分かれしている。
質問で始めると会話を続けるしかないが、宣言で始めると**引ける**。
引けるから観察できて、観察できるから質問が1つで済む。

## ★ そして、ここが大阪の数字に繋がるかもしれない

この人の型は**言葉をほとんど必要としない。**
観察で軸を立て、現物を足に乗せ、短い断定で決める。

4件中3件が海外客（2件は英語も通じない翻訳接客）で、**全件成約している。**

一方、掲示フローは**質問から入る型**。
翻訳を挟むと、

- 質問→翻訳→回答→翻訳 で時間がかかる
- ニュアンスが落ちる
- 海外客の**滞在時間が短い**（店長会10/6で大阪・原宿の課題として報告済み）

> **大阪のクロージング56.7%（4店最低）は、
> 海外客が増えた売場で、他スタッフが質問型のまま戦っているからではないか。**

これは検証可能な仮説。

### 検証の方法

1. 大阪の他スタッフの接客を記録する（**統括の接客ではなく**）
2. 海外客と日本人客でクロージングを分けて見る
3. 観察起点で入ったケースと、質問起点で入ったケースを比べる

# まとめ：現場に渡すなら、この5行

```
0. 来店直後に必ず声をかける。質問ではなく宣言で。
   「サイズも出すんで、なんでも言ってください」── そして引く
1. 聞く前に見る。足が止まった／二度手に取った／触った回数で仮説を立てる
2. 仮説は「短い質問ひとつ」で確認する。当たったらそれが今日の軸
3. 説明しない。持ってくる。欠品でも次を持ってくる
4. 決めるときは優劣を言わず、両方に役割を与える。押す。ただし引き際で引く
```

**そして「決まった直後に離席しない」。** これだけが、唯一の失注原因。

---

## この型を一行で言うと

> **出して、引く。**

0 で声を出して引く。4 で押して引く。
**渡すものを渡したら、判断は客に返す。** それを接客の両端でやっている。

「押さない接客」ではない。**出し切った上で、決定権だけ返している。**
