# リスクの伝え方 ── 「不安喚起」をどう扱うか

> 作成：2026-10-25
> 問い：「不安を植え付けてから解消する」接客動線は有効か

---

# 結論

**技術としては有効。ただし「植え付ける」と「拾う」は別物で、別物として扱う。**

```
❌ 不安を作る  → 自分が解消する      （マッチポンプ）
✅ 不安を拾う  → 判断材料として渡す  （事実の開示）
```

そして**この店には、作らなくても本物の不安材料が揃っている。**
作る必要がない。

---

# 核心：**不安は、作るものではなく、拾うもの**

これは既存の構造とまったく同じです。

```
① 観察する → ② 短い質問ひとつで確認する
```

不安も同じ。**こちらが指摘するのではなく、相手に言わせる。**

## なぜ「言わせる」方が強いのか

| | |
|---|---|
| **こちらが作った不安** | 客は「売りたいからそう言ってる」と割り引く |
| **客が自分で言った不満** | 疑いようがない。**本人の言葉だから** |

掲示フローの「**足元起点**」は、実はこれをやる装置です。

> 「そのスニーカーいいですね」「どこで買われたんですか?」**「履き心地どうですか?」**

3つ目が仕掛け。**不満があれば、向こうから出てきます。**

---

# 🚫 やってはいけない形（この店では特に危ない）

## ① 相手の今の持ち物を否定する

```
❌「その靴、もう結構へたってますね」
❌「それだとちょっと疲れやすいと思いますよ」
```

**相手の過去の選択を否定しています。** 本人は「見る目がない」と言われたと受け取る。
買ってもらえても、**後から思い出して嫌な気持ちになる**タイプの買い物になります。

```
✅「その靴いいですね、どこのですか?」
　 「履き心地どうですか?」 ← 不満があれば、向こうから出る
```

## ② 作った希少性

```
❌「これ人気なんで、今日中になくなっちゃうかもです」（根拠なし）
❌「今買わないと一生手に入らないですよ」（誇張）
```

店長会も明示的に釘を刺しています。

> **嘘はつかないこと。** 在庫画面を見て、実際に残り僅少のときだけ。
> **この話は事実なので嘘をつく必要がありません。**

## ③ 相手の状況を人質にする

```
❌「旅行中ですよね? 今買わないともう来られないですよ」
```

事実ではあるが、**解決する側ではなく追い込む側に回っています。**

# トークスクリプト

## 型A｜サイズ欠品 ── 最も正当性が高い

### ❌ 悪い例
> 「これもうこのサイズしかないですよ。今買わないとなくなります」

根拠が曖昧で、焦らせているだけ。嘘になりやすい。

### ✅ 良い例
> 「このサイズ、**今これで最後**なんです。
> 次の入荷が本土からなんで**月単位**でかかって、
> しかも**次は厚底の40以上、入ってこない**んですよ。
>
> ── **今日決めなくても全然いいんですけど**、それだけ先にお伝えしときますね」

### 設計のポイント

```
事実 → 影響 → 「今日決めなくてもいい」で引く
```

**最後の一文が全部です。** これがないと脅しになる。
あると「情報として渡された」になる。

> **不安も「出して、引く」。**

※ 在庫画面を見て、**本当に最後のときだけ。**

---

## 型B｜旅行者の時間 ── 追い込まず、解決する側に回る

### ❌ 悪い例
> 「今日しかないですよ。明日には売れちゃうかも」

### ✅ 良い例
> 「**何日までいらっしゃるんですか?**
> ……じゃあ、**〇日まででしたら取っておけます**。
> **今日決めなくて大丈夫ですよ。** 気が変わったら〇日までに来てもらえれば。
>
> うち**19時まで**やってるんで」

### 設計のポイント

相手の制約（滞在期限）を、**こちらが引き受けています。**
不安を作るのではなく、**既にある不安を減らしている。**

10/14 のメキシコ人は、**情報なしで1時間半後に戻ってきました。**
営業時間を渡していれば、確率はもっと上がったはずです。

---

## 型C｜素材・ケア ── 買った**後**に効かせる

### ✅ 良い例（本体が決まった後、レジで）
> 「キャンバスなんで、**最初に一回だけ防水かけといた方がいい**です。
> **雨染みって一回つくと取れない**んで。
>
> うちでは扱ってないんですけど、無印とかで売ってるやつで十分ですよ」

### なぜこれが強いのか

**自分の店で売っていないものを勧めています。**

- 今日の売上にはならない
- でも「この人は売りたいだけじゃない」が一発で伝わる
- そして**再来店の理由**になる（育ち具合を見せに来る口実）

> **買う前の不安は警戒される。買った後の不安は、親切になる。**

同じ情報でも、出すタイミングで意味が逆転します。

---

## 型D｜今の靴への言及 ── 拾う形にする

### ❌ 悪い例
> 「その靴、ソールもう減ってますね」

### ✅ 良い例
> 「その靴いいですね、どこのですか?」
> 「へー。**履き心地どうですか?**」
>
> （客「ちょっと疲れるんですよね」）← ★ 本人が言った
>
> 「あー、それだと**これ全然違う**と思いますよ。履いてみます?」

### 設計のポイント

**不満を、客の口から出させてから使っています。**

こちらが言えば「売り文句」。本人が言えば「自分の課題」。
**同じ内容でも、出所が違うと強さが変わります。**

ここまでが掲示フローの「**足元起点**」。
そこから先の「で、これ履いてみます?」は、**自分で言った不満への答え**になる。

# ⚠️ この店で「不安喚起」が特に効きにくい3つの条件

## 1. 翻訳接客では、ニュアンスが落ちて「脅し」だけ残る

記録4件のうち**3件が海外客**（うち2件は英語も不通）。

「今これで最後なんです、でも今日決めなくていいですよ」の
**後半（引き）が翻訳で落ちると、前半（脅し）だけが伝わります。**

→ 翻訳接客では、**不安の話は短く、1回だけ。**
→ むしろ **型B（時間の解決）**の方が確実に効きます。

## 2. 一見客・通りすがりには、信頼の土台がない

記録4件すべて通りすがり。
**信頼ができていない相手の不安喚起は、ただの売りつけに聞こえます。**

不安喚起が効くのは、**関係ができている常連**か、**事実が明白な場合**だけ。

## 3. 不安で縛ると、戻ってこない

10/14 の学びと真っ向から衝突します。

```
押して → 引いた → 1時間半後に「笑顔で」戻ってきた
```

**不安で縛っていたら、戻ることは「負けを認める」行為になります。**
笑顔で戻ってくる客は、不安で買わせた接客からは生まれません。

# 既存の型との接続

**不安の扱いも「出して、引く」で統一できます。**

| | 出す | 引く |
|---|---|---|
| ⓪ 入口 | 「サイズも出すんで、なんでも言ってください」 | 間を空ける |
| ④ 決め | 「進化系」「人気」 | 「考える」で止める |
| **リスク** | **「このサイズ最後です」** | **「今日決めなくていいですよ」** |

**3回とも同じ形。** 渡すものを渡したら、判断は客に返す。

---

# まとめ：スタッフに渡すなら

```
1. 不安は作らない。拾う。
   「履き心地どうですか?」で、相手に言わせる

2. 事実だけ言う。在庫画面を見てから言う
   「このサイズ最後です」は、本当に最後のときだけ

3. 言ったら必ず引く
   「今日決めなくても全然いいんですけど」を必ず付ける

4. ケアの話は、買った後にする
   買う前は警戒される。買った後は親切になる

5. 相手の今の持ち物を、否定しない
```

---

## 最後に、必要性の話

大阪の**客単価 ¥24,764 は4店で1位**です。
**不安で押さなくても、高いものが売れている店**ということ。

落ちているのは客単価ではなく**セット率（1.14／ベスト1.20）とクロージング（56.7%／最低）**。

不安喚起は**クロージングを押し上げる技**ですが、
この店のクロージングの穴は「決まった直後に離席した」「連れに提案しなかった」で、
**不安が足りなかったからではありません。**

> **優先順位としては、型①〜⑤（二足出し・役割分け・連れ起こし・制約取り・置き土産）の方が上。**
> リスクの伝え方は、その後でいい。
