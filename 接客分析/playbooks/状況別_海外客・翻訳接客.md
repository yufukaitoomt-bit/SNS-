# 状況別 ｜ 海外客・翻訳接客

> **これは A/B/C のローテーションに入れない。** 入り方の比較実験とは別軸の「状況対応」。
> A・B・C のどれを使っていても、相手が海外客ならこのルールを上乗せする。

**根拠：** 2026-10-13（大阪）イングランド女性2人組／海外団体。どちらも翻訳アプリでの接客で成約。

---

## 🔴 最大の違い：**再来店が期待できない**

日本人客なら「入荷したらご連絡します」で次につなげられる。
**旅行者には次がない。** だから──

```
日本人客：欠品 → 連絡先をもらう → 後日成約
海外客　：欠品 → その場で代替を出す → 今日決める
```

**欠品が出た瞬間が勝負。** 保留は失注と同義。

### 🚫 配送は使えない（確認済み・2026-10-14）

**ホテル配送・国際配送は不可。** 「後で届ける」という逃げ道は存在しない。

### 旅行者に使える手は、この3つだけ

| 手 | |
|---|---|
| **今日その場で決めてもらう** | 最優先 |
| **滞在最終日までの取り置き** | 滞在日数を聞いてから「〇日まで」と具体的に |
| **押さずに送り出す** | ← **効く。実証済み** |

### ⚠️ 「考える」を断り文句と決めつけない（2026-10-14）

> 客「寄り道で来たから、ホテルに戻る途中で買うか考える」
> → 取り置きを勧めるが断られる → **押さずに送り出した**
> → **戻ってきて購入** ✅

**「考える」が文字通りの意味であることがある。**
ここで粘ると、嫌われて自然な再来店を壊す。

→ **取り置きは提案する。断られたら引く。** 断られてもダメージはない。

---

## 🔴 欠品が出たら「持ってくる」

口頭の代替提案では弱い。**現物を足に乗せる。**

```
❌  「こちらもいいですよ」（言葉だけ）
✅  代替品を取ってきて、履かせる
```

### 狙っていた要素を引き継ぐ

商品が変わっても、**お客様が本当に欲しかったもの**を残す。

| お客様の狙い | 引き継ぎ方 |
|---|---|
| DIVISION の**ネイビー** | → Resculpt の**ネイビー**を出す |
| **ソールの厚み** | → 厚底の別型（TRACK）も出す |
| 特定の**色** | → 別型の同色 |

「代替品」ではなく「**狙いを叶える別ルート**」として見せる。

---

## 🔴 言葉は短く、断定で

翻訳を挟むと、**長い理由づけはニュアンスが落ちる。**
日本語接客で有効な「〇〇だから△△です」の構文は、翻訳越しだと伝わりにくい。

```
❌  「普通のキャンバスだと優等生になりますが、こちらはスタッズが付いているので
     カジュアルに寄せやすく、今日のお召し物にも合わせやすいと思います」
✅  「似合ってます」「この素材、良いです」「かわいい」
```

**短い断定を、反復する。**
2026-10-13 の1人目は、これで決まっている（本人評価は「ゴリ押し」）。

> ※ ただしこれは n=1 の観察。**日本人客にそのまま転用しないこと。**
> 日本語接客では「かわいいですよ」単体は弱い（誰にでも言える＝誰にも刺さらない）。

---

## 🔴 言葉以外の情報量で勝負する

喋れない分、**見せる・履かせる・並べる**の比重が上がる。

- **複数型を試着させる**（2026-10-13 の団体は3型試着して成約）
- 2色で迷ったら**並べて置く**
- 鏡の前に立たせる
- 自分で履いて見せる

---

## 🔴 迷いは「合わせ方」で決着させる

色やモデルで迷っている客に、**優劣を語っても決まらない。**

```
❌  「どっちもいいですよ」「黒の方が人気です」
✅  「この色なら、こう履くと良いです」（使う場面を描く）
```

**使っている自分の姿が見えた瞬間に決まる。**
2026-10-13 の団体は、Resculpt 2色の迷いをこれで黒に決着させている。

翻訳越しでも、**スマホで着用画像を見せる／自分で合わせて見せる**なら言語に依存しない。

---

## 入り方：ゾーン起点が効く

海外客は**どれが人気か分からない**。だから売場の文脈そのものが情報になる。

> 「ここは**人気ゾーン**です」
> 「このあたりは**厚底**です」

商品を名指ししないので押し付けにならず、断られにくい。
そこから「どんなものを履きますか?」とヒアリングに入る。

---

## 翻訳接客で見落としがちなこと

### ⚠️ 翻訳を打っている間が「離席」と同じになる
画面を見ている時間は、お客様にとっては放置されている時間。

- 定型文は**あらかじめ用意しておく**（サイズ確認・在庫確認・試着の声かけ）
- 打ちながらでも**目を合わせる／商品を指す**

### ⚠️ 「分かりました」が分かっていないことがある
翻訳越しの同意は、**理解ではなく礼儀**のことがある。
**言葉の返事ではなく、行動（履く・鏡を見る・手に取る）で確認する。**
