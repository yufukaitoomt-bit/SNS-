# テンプレート C ｜ スタイリング起点型

> **仮説：** **自分の服を具体的に見てもらえた相手**は、警戒を解いて話を聞く。
> 商品の話から入るのではなく、**お客様が今日着ている服**から入る。
>
> **根拠：** 2026-10-12（大阪）。「韓国系の服装 → 普通のキャンバスよりスタッズの方が合わせやすい」が、この日いちばん人を動かした一言だった。

**向いている客：** 服装にこだわりが見える人、系統がはっきりしている人、感度の高い若年層

---

## 手順

### ① 今日の服装を、具体的に1点褒める

**抽象的な褒め方は逆効果。** 営業トークだと即バレる。

| | |
|---|---|
| ❌ | 「おしゃれですね」 → 誰にでも言える＝誰にも刺さらない |
| ❌ | 「かわいいですね」 → 商品を売りたいだけに聞こえる |
| ✅ | 「**そのパンツのシルエットいいですね、どこのですか?**」 |
| ✅ | 「**その靴、〇〇ですよね。いいの履いてますね**」 |
| ✅ | 「**その重ね方、めっちゃ good です**」 |

**ポイントは「固有名詞」か「具体的な部位」。**
相手が選んだものを**正確に見ている**ことが伝わると、そこで信頼が立つ。

---

### ② 系統を言語化する

> 「韓国系で揃えてはる感じですね」
> 「ストリート寄りですよね」

**相手の系統を言い当てる。** 当たっていれば一気に距離が縮まる。
外していても「あ、違います、〇〇っぽいのが好きで」と**向こうから情報が出る**ので、どちらに転んでも得。

---

### ③ その服に接続して商品を出す

```
お客様の服  →  だからこれが合う  →  商品
```

> 「**それなら、これめちゃくちゃ合いますよ。**
> 普通のキャンバスだとちょっと優等生になるんですけど、
> こっちスタッズ付いてるんで、今日の感じにそのままハマります」

**商品の説明をしているのではなく、「あなたの今日のコーデの話」をしている。**
主語がお客様のままなので、売り込みに聞こえない。

---

### ④ 合わせ方を具体的に描く

> 「そのパンツなら、丈をちょっと溜めて履くと良いです」
> 「上に〇〇を羽織ったら、もう完成します」

**今日の服 + この商品 = 完成形**を、言葉で見せる。
お客様の頭の中に絵が描けた時点で、試着は通る。

---

### ⑤ 試着へ

> 「一回合わせてみましょう。サイズお出しします」

**「合わせてみる」**という言い方を使う。
「試着」より目的がはっきりしていて、断りにくい。

---

## ⑥ 以降は【共通ルール】へ

→ ジャストサイズが出たら、その場で決める
→ アップセルは本体確定後
→ 欠品なら必ず連絡先

---

## このテンプレの弱点・注意

- **褒めが外れると最悪。** 嘘や社交辞令は即バレる。**本当に良いと思った点だけ**言う
- 良いと思える点が見つからない客には使えない → A型かB型に切り替える
- 相手の系統を**決めつけすぎない**。「〇〇系ですよね?」と断定するより「〇〇寄りな感じですかね」と余白を残す
- 服装への言及を**不快に感じる人もいる**（じろじろ見られたと感じる）。相手の反応を見て、硬ければすぐ商品の話に切り替える

### 使ってはいけない相手
- 服装に明らかに無頓着な人
- 急いでいる人
- 外見への言及を嫌がりそうな雰囲気の人
