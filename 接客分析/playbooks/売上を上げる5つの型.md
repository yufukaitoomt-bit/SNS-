# 売上を上げる5つの型

> 作成：2026-10-19
> 用途：**統括が自分の接客感として持ち、スタッフに応じて言語化して渡すための原型**
> ※ 以下の「新人／中堅／できる人」は、そのまま読み上げる台本ではなく**渡す深さの目安**

---

## 土台：この5つの型は、すべて同じ1つの動作でできている

> ## **出して、引く。**

```
入口：声をかける → 引く → 客が動く → 観察できる
出口：押す       → 引く → 客が決める → 納得する／戻ってくる
```

**渡すものを渡したら、判断は客に返す。**
これだけは全員に最初に渡す。5つの型は、全部この応用。

---

# 型① 二足出し ── 「買うか」を「どっちか」に変える

## 引き金
試着に入るとき。**例外なく毎回。**

## 動き
```
1足目：客が見ていたもの
2足目：色違い か 同価格帯の別モデル
サイズ：ジャストと＋0.5の2つ
```
> 「サイズ出してきますね。**こっちの色も一緒に持ってくる**んで、履き比べてみてください」

## なぜ効くか

**1足だけだと、客の頭の中は「買う／買わない」。**
**2足あると「どっちにするか」に変わる。**

買わないという選択肢が、自然に外れる。

## 根拠
- 店長会：名古屋の処方。**「試着個/組が一番先に動く」**
- 10/13 団体は3足持っていって成約
- 10/12 は男性の42と女性の37を**同時に回収**している（往復を束ねる）

## 渡し方

| | |
|---|---|
| **新人** | 「**試着は必ず2足。**これだけ守って」── 理由は後でいい。動作だけ渡す |
| **中堅** | 「2足目は**比較になるもの**を選ぶ。似すぎててもダメ、違いすぎてもダメ」 |
| **できる人** | 「2足目で**軸を作ってる**。客がどっちを選ぶかで、その人の好みが分かる」 |

# 型② 役割分け ── 優劣を言わない

## 引き金
客が2つで迷っているとき。**または2つ目を足したいとき。**

## 動き
**「こっちがいい」と言わない。両方に“使う場面”を割り当てる。**

> 「**黒はコーデに馴染む。ネイビーは少し外しっぽい感じで使える**よ」

## ★ この型には2つのモードがある

### モードA：選ばせる（1足売る）
迷いを決着させる。客が自分の生活に近い方を選ぶ。

### モードB：併せる（2足売る）← **ここがまだ使えていない**
同じ言い方で、**「どっちか」ではなく「両方いる」**に持っていける。

> 「**普段履きはこっち。** でも**雨の日とかガシガシ履く用**にもう一足あると、
> こっちが長持ちするんですよ」

**用途が違えば、2足は別物になる。** 色違い2足は高く感じるが、役割が違えば高く感じない。

## なぜ効くか
- 選択の**軸は店員が設定し、選ぶのは客**。「選ばされた」感がない
- 選ばなかった方を**否定していない**ので、好みを否定された感覚がない

## 根拠
10/13 団体：この一言で、**客が自分で言っていた希望（ネイビー）と違う黒**に着地した。

## 渡し方

| | |
|---|---|
| **新人** | 「**どっちがいいですよ、と言わない。**『こっちは〇〇な時、こっちは△△な時』で言う」 |
| **中堅** | 「迷ってる時は**選ばせる**。決まってる時は**用途を足して2足**にできる」 |
| **できる人** | 「**選ばせてる風に、選ぶ軸をこっちが決めてる。**だから納得が強い」 |

# 型③ 連れ起こし ── 付き添いを客に変える

## 引き金
**一人目が決まった瞬間。** ここが起点。

## 動き
```
1. 一人目を接客しながら、連れが何を触っているかを目の端で見ておく
2. 一人目が決まったら、すぐ連れに軸を向ける
3. 「同じもの」ではなく、連れ専用の理由を渡す
```

> 「お揃いもいいですけど、**〇〇さんは馴染む黒、△△さんは外しのネイビー**にすると、
> 並んだ時すごく良いですよ」

## なぜ効くか

**連れは「付き添い」として店に入ってくる。** 自分が買う前提がない。
同じものを同じように出されても、**買う理由がない。**

## 根拠（きれいに分かれている）

| | 連れへの提案 | 結果 |
|---|---|---|
| 10/12 | 「シミラーで合わせたら可愛い」 | **2回目の試着まで戻せた** |
| 10/13 Brunch | **なし**（同じものを出しただけ） | **1回履いて終了・非購入** |

## 渡し方

| | |
|---|---|
| **新人** | 「**連れの人にも必ず一声かける。**『〇〇さんはどうですか?』だけでいい」 |
| **中堅** | 「一人目が決まった瞬間が合図。**連れには違うものを出す**」 |
| **できる人** | 「一人目の接客中に**連れを観察しておく。**決まった瞬間に軸が出せる」 |

# 型④ 制約取り ── 「今日じゃない理由」を先に潰す

## 引き金
**接客の早い段階。** 好みを聞くのと同じくらいのタイミング。

## 動き
好み（色・系統）だけでなく、**状況**を取る。

> 「今日はこの後どこか行かれます?」
> 「旅行ですか? **何日くらいいらっしゃるんですか?**」

## なぜ効くか

**失注の障害が「商品」ではなく「状況」のとき、商品の訴求を重ねても効かない。**

| 障害 | 効く手 |
|---|---|
| 商品の魅力が足りない | 商品の訴求 |
| **荷物・移動・時間** | **営業時間を渡す／滞在最終日までの取り置き** |
| 迷っている | 取り置き・最後の1点 |

**道具を間違えると、何を重ねても効かない。**

## 根拠
10/14：失注しかけた理由は「**寄り道で来たから、ホテルに戻る途中で考える**」。
これが分かったのは**接客の最後**だった。
打った手（「進化系」「人気」「取り置き」）は、**どれも障害の種類に合っていなかった。**

※ 結果的には1時間半後に戻って成約。ただし早く分かっていれば組み立てが変わった。

## 渡し方

| | |
|---|---|
| **新人** | 「**『今日はこの後どこか行かれます?』**を早めに1回聞く」 |
| **中堅** | 「**買えない理由は3種類。**商品／迷い／状況。どれかで出す手が変わる」 |
| **できる人** | 「障害の種類に合わない手は、何回打っても効かない。**まず種類を特定する**」 |

# 型⑤ 置き土産 ── 選ばなかった方に、役割を残す

## 引き金
**クロージングの直後。** 買うものが決まった後。

## 動き
選ばれなかった方を、**否定したまま終わらせない。**

> 「**ネイビーは外しで使える**んで、2足目の時はぜひ」
> 「このリボン、**付けると一気に可愛い寄り**になります。気分で変えられるんで」

## なぜ効くか

- 客は「**次に買うもの**」を持って帰る
- 選ばなかった方を否定していないので、**今日の選択への満足も落ちない**
- アクセサリー（¥3,900）なら**今日その場で2点目になる**

## 根拠
- 10/13 団体：「ネイビーは外しで使える」は、**意図せず次回の種になっている**
- 店長会 2-3：smile 専用アクセのアタッチ率 **13.5%**、BBIMP **8.3%**、在庫181点
- 「2足目（¥21,000）よりハードルが低い」と店長会が明記

## ⚠️ 出すタイミングを間違えない

**本体が決まった後。レジまでの数十秒。**

10/12 は、ジャストサイズが決まった**直後にリボンを探しに離席**して、本体ごと失っている。
**アップセルは、迷っている人を決めさせる技術ではない。**

## 渡し方

| | |
|---|---|
| **新人** | 「**smile と BBIMP を買う人には、レジで専用パーツを必ず見せる**」 |
| **中堅** | 「**本体が決まってから**出す。決まる前に取りに行かない」 |
| **できる人** | 「選ばなかった方に役割を残す。**今日の2点目にも、次回の理由にもなる**」 |

---

# 🚫 全員共通の禁止事項（1つだけ）

## **ジャストサイズが決まった直後に、その場を離れない。**

```
サイズが合った → 「じゃあこちらでご用意しますね」 ← 先に決定を固定
                 ↓
                 それから動く
```

どうしても離れるなら、
> 「**こちらお取り置きしておきますね。30秒だけいただきます**」

**無言で消えない。** 客は「待つ」ではなく「見て回る」に行動を変える。

### 根拠
4件で**失注はこの1件だけ**。
ジャストサイズが出た直後に離席 → 客が別の（在庫のない）商品を自分で見つけた → 失注。

# 型の配り方

## レベル別に、渡す数を絞る

| | 渡すもの |
|---|---|
| **新人** | 「出して引く」＋ **型①（二足出し）** ＋ 禁止事項。**これだけ** |
| **中堅** | ＋ 型②（役割分け・選ばせるモード）＋ 型④（制約取り） |
| **できる人** | ＋ 型②モードB（併売）＋ 型③（連れ起こし）＋ 型⑤（置き土産） |

**全部渡すと何も残らない。**
店長会も「**全部やろうとすると何も残りません**」と書いている。

## どの指標に効くか

| 型 | 効く指標 |
|---|---|
| ① 二足出し | **試着個/組** →（店長会：一番先に動く） |
| ② 役割分け A | クロージング |
| ② 役割分け B | **セット率** |
| ③ 連れ起こし | **セット率・決定率** |
| ④ 制約取り | クロージング（失注の予防） |
| ⑤ 置き土産 | **セット率**・再来店 |
| 禁止事項 | クロージング |

**③②B⑤がセット率に効く。** 大阪1.14／ベスト原宿1.20。
店長会で「**セット率1.00超えは和田さんだけ**」と名指しされている弱点。
