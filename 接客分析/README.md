# 接客分析アーカイブ

接客1件ごとの記録を蓄積し、**データからマニュアルを作る**ためのリポジトリ。

---

## なぜ記録するのか

1件の接客を振り返るだけなら記憶で足りる。蓄積する目的は別で、

- 「効いた一言」が**何度も効いている**ことを証明する → マニュアルに載せる根拠になる
- 「外した一手」が**同じ型で繰り返されている**ことを発見する → 仕組みで潰す
- 失注理由を数えて、**接客の問題か店舗の問題かを切り分ける**

感覚ではなく件数で語れるようになることが狙い。

## ディレクトリ構成

```
接客分析/
├── README.md                    # このファイル（運用ルール＋インデックス）
├── _TEMPLATE.md                 # 記録テンプレート（コピーして使う）
├── playbooks/                   # ★現場で使う接客テンプレート
│   ├── README.md                #   比較実験の設計書
│   ├── 共通ルール.md             #   全テンプレ共通・必ず守る3鉄則
│   ├── A_観察ヒアリング型.md
│   ├── B_試着ファースト型.md
│   └── C_スタイリング起点型.md
├── logs/                        # 全接客の1行ログ（毎回・30秒）
│   └── YYYY-MM_実験ログ.md
├── records/                     # 詳細記録（印象に残った接客のみ）
│   └── YYYY-MM-DD_客層_商品.md
└── transcripts/                 # 音声の文字起こし（あれば）
    └── YYYY-MM-DD_音声文字起こし.txt
```

### 使い分け

| | いつ書くか |
|---|---|
| `logs/` | **毎回。** 1行だけ。これが集計の母数になる |
| `records/` | **印象に残った接客だけ。** 良かった／悪かったの理由を掘る |

全部を詳細記録しようとすると続かない。**ログは毎回、詳細は時々。**

## 記録のルール

### ファイル名
`YYYY-MM-DD_客層_商品.md`
例：`2026-10-12_カップル_SMILE-CHAOS.md`

同日に複数ある場合は末尾に連番 → `2026-10-12_カップル_SMILE-CHAOS_2.md`

### 書く範囲
**接客直後、記憶が新しいうちに。** 完璧に書く必要はない。
最低限これだけあれば後から分析できる：

- 試着の順番（商品・色・サイズ）
- 結果（買ったか／買わなかったか・理由）
- 自分が言った言葉で覚えているもの

### タグ
分岐点には必ずタグを付ける。後で横断検索して集計するため。

| タグ | 対象 |
|---|---|
| `#アプローチ` | 声かけのタイミング・入り方 |
| `#ヒアリング` | 質問・情報収集 |
| `#提案` | コーデ提案・商品説明・訴求 |
| `#試着誘導` | 試着に持ち込む動き |
| `#クロージング` | 決めにいく一手 |
| `#アップセル` | 2点目以降・付属品 |
| `#欠品対応` | 在庫がない時の動き |
| `#次回接点` | 連絡先・再来店の仕掛け |
| `#売場` | ディスプレイ・在庫配置など店舗構造 |

## 現時点で見えている仮説

件数が少ないため「仮説」。同じパターンが3件たまったらマニュアルに昇格させる。

---

### ★ 仮説0｜欠品の結果を分けるのは「その場で次を出したか」 — 3件で一致

3件すべてで欠品が発生し、**結果が分かれた。**

| | 10/12 SMILE 黒37 | 10/13 Brunch 茶 | 10/13 DIVISION |
|---|---|---|---|
| 欠品が分かった時、販売員は | **離席中** | 在席 | 在席 |
| 次の動き | **なし**（「36ならある」で停止） | 別カラーを押す | 代替品を**持ってきて履かせる** |
| 結果 | **失注** ❌ | **成約** ✅ | **成約** ✅ |

欠品そのものは失注理由ではない。**欠品の直後に次を出せたかどうか**で分かれている。

> **欠品 →（間を空けず）次の一手。** 言葉だけでなく、現物を持ってくる。

3件で一致しているため、これは**最もマニュアル昇格に近い**。
ただし 10/12 は日本人・10/13 は海外客で条件が違うため、同条件での再現を待つ。

### 仮説① ジャストサイズが出た瞬間が、クロージングの最大圧
サイズが決まった直後は購買意思が最も高い。ここで離席すると意識が「買う/買わない」から「他に何かないか」に移る。
→ **離席はクロージング後。**（根拠：2026-10-12）

**精緻化（2026-10-13）：** 危険なのは「ピーク時の離席」であって、往復そのものではない。
10-13 はサイズを3回変えて出しても成約している。**サイズ出しの往復は客も「待つ前提」**で見ており、
意識が離れない。**離れてはいけないのは「決まった直後」の一点。**

### 仮説⑦ サイズで迷う客は、サイズの話では決まらない
3回サイズを変えても決まらなかった客が、「似合ってる」「素材」「かわいい」の断定で決着した。
サイズ迷いの正体は「本当にこれでいいのか」という不安であり、**断定がその不安を切る。**
→ **サイズを3回出しても決まらなければ、サイズの話をやめて断定に切り替える。**（根拠：2026-10-13）

### 仮説⑧ 連れには「連れ専用の理由」が要る
同じものを同じように出しても、連れには自分が買う理由がない。
- 2026-10-12：「シミラーで合わせたら可愛い」→ 連れを2回目の試着まで戻せた
- 2026-10-13：連れ専用の提案なし → 1回試着して終了
→ **一人目が決まった瞬間が、連れへの横展開の起点。色違い・別型など「別の理由」を渡す。**

### 仮説② アップセルは本体確定前に出すと、本体ごと失う
付属品を取りに行っている間に、本体への集中が切れる。
→ **「ご用意します」を取ってから足す。**（根拠：2026-10-12）

### 仮説③ 欠品は失注理由ではなく、連絡先をもらう正当な理由
「入荷したら一番にご連絡します」は欠品時にだけ自然に使えるカード。
→ **欠品が出たら必ず連絡先を取る。**（根拠：2026-10-12）

**※ 海外客には適用しない。** 再来店がないため連絡先の価値が低い。
→ 海外客は「連絡先」ではなく「**その場で代替**」（根拠：2026-10-13 × 2件）
→ [状況別_海外客・翻訳接客.md](playbooks/状況別_海外客・翻訳接客.md)

### ★ 仮説⑤ 迷いは「どっちが良いか」ではなく「**両方に役割を与える**」と決まる

2026-10-13 海外団体のクロージング。**「黒の方がいい」とは一言も言っていない。**

> 「**黒はコーデに馴染む。ネイビーは少し外しっぽい感じで使えるよ**」

| | |
|---|---|
| 黒 | 馴染む（日常・汎用） |
| ネイビー | 外し（アクセント・上級者向け） |

普段長ズボンでメインの一足を探している人は、**自分で「馴染む方」を選ぶ。**

**選択の軸は販売員が設定し、選ぶのはお客様。** だから納得が強い。
さらに当初の希望（ネイビー）を否定していないので、**好みを否定された感覚がなく、
選ばなかった方が次の一足への伏線になる。**

→ [共通ルール - 決めきる技術](playbooks/共通ルール.md#決めきる技術)

### ★ 仮説⑩ 試着は「今日の服」ではなく「**普段の条件**」で合わせる

2026-10-13 のお客様は**半ズボン**。しかし「**普段は長ズボンが多い**」と発言。
→ 販売員は**デニムを店から持ってきて**、鏡の前で合わせさせた。

**お客様が買っているのは「今日の一足」ではなく「これから毎日履く一足」。**
今日の服に合わせて選ばせていたら、家に帰って合わない。

**再現するのは「服」ではなく「条件」。**
このお客様は普段デニムを履かない。デニムは「長ズボンの丈で見る」条件を作る**道具**。
手元の在庫で条件が作れれば、その商品自体が客の好みである必要はない。

→ **発言と今日の服装にズレがあったら、店の在庫で普段の条件を再現する。**

### 仮説⑫ 道具として使った商品を、無理に売らない
2026-10-13、デニムは合わせただけで提案していない（客は普段デニムを履かない）。
「せっかく持ってきたから」で勧めると**「結局売りたいだけ」が透けて、本体の提案まで信用を失う。**
→ 鉄則2（アップセルは本体確定後）は「**合うものがある時だけ**」が前提。

### 仮説⑪ 2つで迷ったら片足ずつ履かせる
並べて見るのではなく、自分の足で同時に比較させる。鏡の前まで連れて行く。
迷いが「記憶の中の比較」から「目の前の比較」になる。（根拠：2026-10-13）

### ★ 仮説⑨ お客様の「探しているもの」は、入口の仮説にすぎない

2026-10-13 海外団体で、お客様が口にした希望は3つ。

| 言っていたこと | 結果 |
|---|---|
| DIVISION（モデル指定） | 在庫なし → 別モデルを購入 |
| ネイビー（色指定） | 試着したが選ばず |
| シルバー系を探している | 選ばず |

**モデルも色も、当初の希望を満たさない「Resculpt の黒」が売れた。**

ただし販売員は希望を**一つも無視していない。** 全部に現物で答えている
（DIVISION→Resculpt、シルバー系→TRACK、ネイビー→Resculpt のネイビー）。

→ **言われた条件に縛られると売れない。無視しても売れない。**
→ **一つずつ現物で答えて、試させる。** その過程で本人も知らなかった正解が出てくる。

これは「欠品対応」より広い原理かもしれない。**希望が叶わない時こそ、出し続ける。**

### 仮説⑥ 「二度手に取った商品」はシグナルとして強い
足を止めただけより、一度置いて再び手に取った商品の方が確度が高い。
→ **一周させて、2回目を待つ。**（根拠：2026-10-13 イングランド女性2人）

### 仮説④ 試着エリア正面のディスプレイは、在庫のある色・サイズにする
欠品カラーを飾ると、お客様の欲求が買えないSKUに逃げる。
→ **ディスプレイは「今日お渡しできる一足」を映す鏡。**（根拠：2026-10-12）
